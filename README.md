A real product for restaurants in Barranquilla: the owner edits a menu in a web editor and it
renders **live on Samsung Smart TVs** as a digital menu board. One product, three surfaces + infra.

| Repo | Surface | Stack |

| [signage-tv](https://github.com/jonathanDavid/signage-tv) | Samsung Tizen / SSSP player | Vanilla TS · esbuild (ES2017) |
| [signage-infra](https://github.com/jonathanDavid/signage-infra) | Infrastructure | Terraform · ECS · RDS · K8s |
